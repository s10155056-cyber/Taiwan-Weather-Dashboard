# 島嶼日常｜台灣天氣生活看板

以單一 HTML 檔案製作的繁體中文天氣生活看板，支援台灣縣市與行政區選擇、模擬天氣與 AQI、三時段預報，以及依降雨、氣溫和 AQI 產生的生活建議。

本專案由本人規劃，並使用 AI 協助開發。

## 專案內容

- `index.html`：完整網頁，包含 CSS、JavaScript 與地區資料，不需安裝套件。
- `.gitignore`：避免常見金鑰、環境設定檔及打包檔誤上傳。

## 本機預覽

直接用瀏覽器開啟 `index.html` 即可。也可以將 `demo` 資料夾發布為 GitHub Pages 網站。

沒有輸入 API 金鑰時，頁面使用模擬資料；訪客可以在「資料設定」輸入自己的中央氣象署授權碼與環境部 API 金鑰，頁面會直接向官方 API 發出請求。輸入的金鑰只保留在目前頁面的記憶體，重新載入頁面後需重新輸入；若 API 請求受 CORS、網路或資料限制阻擋，頁面會提示原因並以模擬資料補位。

模擬資料不代表官方即時觀測，請勿用於天氣或健康決策。

## 發布到 GitHub

1. 建立 GitHub repository。
2. 上傳 `index.html`、`README.md`、`.gitignore`。
3. 不要上傳 API 授權碼、API 金鑰、密碼、含有秘密資料的環境設定檔，或顯示這些資料的截圖。
4. 若要使用 GitHub Pages，在 repository 的 **Settings → Pages** 選擇發布來源，完成後即可使用網站連結。

此資料夾的壓縮檔是方便下載的副本；通常上傳解壓後的專案檔案即可，壓縮檔已由 `.gitignore` 排除。

## API 金鑰安全

瀏覽器前端不能安全地保管秘密。把金鑰寫進 HTML/JavaScript 會讓所有訪客從原始碼看到。此專案提供的設定欄位是讓**每位使用者輸入自己的金鑰**：金鑰不會被寫進 GitHub 專案或瀏覽器儲存空間，但呼叫官方 API 時會由該使用者的瀏覽器送出，該使用者可以在自己的開發者工具中看到。請勿在共用電腦輸入，也不要把自己的金鑰交給公開頁面代為共用。

若要增加即時資料，建議保留此靜態頁面作前端，另外建置受控的後端代理：

1. 將中央氣象署授權碼與環境部 API 金鑰設在後端部署平台的 **Secrets／環境變數**，不要放在前端程式碼或 GitHub。
2. 前端只呼叫自己的代理端點，由代理代為呼叫官方 API；代理應限制可用資料與請求頻率。
3. 公開部署後檢查 GitHub 原始碼、部署檔案及瀏覽器網路請求，確認沒有秘密值。
4. 若金鑰曾經提交到 GitHub，即使刪除檔案，也應立即到資料平台撤銷並重新申請；Git 歷史仍可能留有舊值。

純靜態 GitHub Pages 無法提供私密的伺服器端 API 金鑰。若要讓所有訪客共用即時資料，請建立後端代理並將金鑰設在部署平台的 Secrets；否則可讓每位訪客自行輸入自己的金鑰，或不輸入而使用模擬資料。

## 資料與使用說明

即時資料尚未接入。若日後採用政府公開資料，請依資料平台的 API 使用條款及資料集授權標示來源：

- [中央氣象署氣象資料開放平台](https://opendata.cwa.gov.tw/)
